### 安全要求

- 不读取、上传或提交真实私钥、密码和完整令牌；不自动设置免密管理员权限。
- 不把项目的临时连接策略替换成某台运维服务器的永久密钥授权。
- 不隐蔽驻留，不绕过 UAC，不开放公网端口。
- 只读界面预览只取消配置弹窗；不运行 `gui --configure`，不自动安装组件、创建账号 / 服务或修改防火墙。
- 不把 WinRM revoke 当作 SSH revoke；宿主退出 / 到期停止 SSH 子进程不等于全部系统资源已经删除，仍须实机核对恢复。
- 不删除同级 `gitlab-ops` 或本项目的兼容代码、离线包、测试、生成物来“整理”。确需清理时按用户明确范围确认。
