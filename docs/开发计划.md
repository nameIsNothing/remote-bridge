# Remote Bridge 分阶段开发计划

## 当前开发位置

2026-10-08 界面调整基线：Go 骨架、模型、发现、管理端和目标端已有实现，默认 Windows 局域网 SSH，WinRM 保留兼容。当前处于 Phase 1 实验版加固和验收阶段，不能从零重复 Phase 0，也不能把后续路线写成已完成。详细事实、测试状态和缺口以 `开发交接.md` 为准。

0.2.0 已实现原生“检查 / 连接”界面、配置确认与 UAC 自动继续、短期授权复用、协议就绪检查、认证反馈和清理错误显示；旧控制台 EOF/读取错误默认取消继续保留。当前用户定位为可信局域网内的自用小工具，保留 LocalSubnet，独立 SSH 撤销暂不优先，自用不要求签名。独立 SSH 撤销、异常退出后的完整恢复、生命周期审计和新版两机验收仍是后续项，按用户任务推进。签名与安装前可信验证仅在后续正式分发时作为要求；下列“交付/验收”是阶段目标，不代表已经全部通过。

## Phase 0：工程骨架与协议（1 个开发切片）

源码已有相应基础和测试；新窗口先检查现状，不重新创建骨架。一次性数字配对码模块尚未接入 CLI，元数据模型不是统一运行时连接接口。

### 交付

- 初始化 Go 多模块或单模块工程。
- 定义设备、配对、会话、隧道和审计事件模型。
- 定义本地配置文件和退出码。
- 提供 `docs/` 中的运行、测试和回滚说明。

### 验收

- `go test ./...` 通过。
- 可以创建和校验一次性配对码。
- 不输出密码、私钥和完整令牌。

## Phase 1：Windows 局域网直连 MVP

### 交付

- Go 原生 Windows 检查 / 连接窗口，配置确认后自动广播，首次批准后复用授权；保留显式 SSH / WinRM 控制台入口。
- 检查管理员权限、OpenSSH/WinRM、网络类型和目标 IP，明确需修改的系统资源。
- SSH 临时公钥配对、独立 sshd、临时维护账号与防火墙；WinRM 使用计划化配置。
- 输出设备信息和管理端连接命令。
- 简易局域网模式提供短期 UDP 发现（只广播/返回非敏感元数据，不交接密码）。
- 提供区分传输类型的撤销/恢复入口和清理结果；当前 WinRM revoke 不能处理 SSH 状态。
- `bridge-cli check` 检查 WinRM TCP 端口；SSH 需验证就绪、身份、配对和实际命令执行，不把端口可达当成全部验收。

### 验收

- 全新 Windows 10/11 虚拟机可以一次运行完成配置。
- 管理机可以通过产品配对流程执行 `hostname`、`whoami`、磁盘和网络检查，拒绝配对时不能登录。
- 目标机窗口保持打开时，管理机 `bridge-cli discover --once` 可以找到目标；发现失败时仍可使用屏幕显示的 IP。
- 严格模式只允许管理机 IP 访问；简易实验模式明确标记为 `LocalSubnet`，仅用于可信测试网。
- 正常结束、TTL、重复启动、失败重试与异常退出分别验收，计划拥有的账号、进程、规则和目录能撤销；不得误删已有系统资源。
- 配置确认在 EOF/读取失败时默认取消，清理失败保留状态并明确报告。
- WinRM 回滚只处理计划拥有的账号和规则；listener、服务和 quickconfig 产生的额外策略改变需单独评估恢复。
- 验证安装包与 manifest 的可信来源及正式发布签名，SHA-256 相符不能单独替代签名。

## Phase 2：公网 Relay 与反向隧道

尚未实现；Phase 1 的安全和生命周期验收完成后再按用户需求开展。

### 交付

- Relay 服务和 Docker Compose 部署文件。
- TLS、设备注册、一次性配对和设备撤销。
- 目标机出站隧道。
- 管理端本地端口映射。
- 会话超时、断线重连和最大连接数限制。

### 验收

- 目标机和管理机处于不同网络时，可以通过 Relay 建立 Shell 会话。
- 目标机不需要开放公网入站端口。
- Relay 重启后旧令牌不能恢复会话。
- 审计日志包含设备、操作者、开始时间、结束时间和结果。

## Phase 3：Ubuntu 与 macOS

尚未实现产品启动器/适配器。人工使用管理机系统 SSH 连接 Ubuntu，不是此阶段的产品验收。

### 交付

- Linux/macOS 启动器。
- SSH 临时密钥和系统服务检查。
- x64/ARM64 构建产物。
- 系统差异和权限提示文档。

### 验收

- Ubuntu 可以通过 Bash 建立会话。
- macOS 可以通过 Zsh 建立会话。
- 目标机没有安装 Go、Node 或 Python 也能运行。
